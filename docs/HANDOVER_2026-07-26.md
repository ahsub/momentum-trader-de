## 🔴 Kritisch: KO-Aggregator Datenstruktur

**Erkenntnis:** Das Backup (`tr_backup_latest.json`) enthält **keine Marktdaten** — nur Trade-Evaluierungen.

```
Backup-Struktur:
├── tr:eval:YYYYMMDD:NNNN  → Minervini-Signale (sym, strat, r7, trade.st)
├── tr:state:...           → State-Machine
├── tr:pending:...         → Pending Orders
├── tr:history:...         → Trade-History

❌ Fehlt: price, ema20/50/200, rsi14, hvp, regime, sma50/200
```

**Konsequenz:** Der Options-Scanner kann aktuell **keine echten Kandidaten** filtern (Preis, Trend, RSI fehlen).
